# 🍲 MealCraft - Flutter Recipe App

![Flutter](https://img.shields.io/badge/Flutter-%2302569B.svg?style=for-the-badge&logo=Flutter&logoColor=white)
![Dart](https://img.shields.io/badge/Dart-%230175C2.svg?style=for-the-badge&logo=dart&logoColor=white)
![BLoC](https://img.shields.io/badge/BLoC-State_Management-blue?style=for-the-badge)

**MealCraft** is a beautifully designed, cross-platform food discovery application built with Flutter. It allows users to explore global recipes, browse diverse food categories, and view detailed cooking instructions. 

The application is engineered with a **Modular/Clean Architecture** to ensure maximum scalability, maintainability, and a seamless developer experience.

## ✨ Key Features

* **Discover Recipes:** Browse a wide variety of trending meals and global cuisines.
* **Smart Filtering:** Explore meals by specific categories.
* **Detailed Recipe View:** A modern, layered UI displaying meal details, ingredients, and cooking times.
* **Robust Search:** Efficiently fetch accurate meal details using dedicated API endpoints.
* **Offline Error Handling:** Graceful UI feedback when the network is disconnected.

## 🛠️ Tech Stack & Libraries

* **Framework:** [Flutter](https://flutter.dev/)
* **Language:** [Dart](https://dart.dev/)
* **State Management:** [flutter_bloc](https://pub.dev/packages/flutter_bloc) (Cubit)
* **Networking:** * [Dio](https://pub.dev/packages/dio) (HTTP client)
  * [Retrofit](https://pub.dev/packages/retrofit) (Type-safe REST client)
* **Data Parsing:** [json_serializable](https://pub.dev/packages/json_serializable) & [build_runner](https://pub.dev/packages/build_runner)
* **UI & Caching:** [cached_network_image](https://pub.dev/packages/cached_network_image)
